# Superstore Sales Dashboard

## Project Overview

This project is an interactive Excel dashboard created using the Superstore dataset.

The dashboard provides insights into sales, transactions, quantity ordered, shipping modes, regions, categories, customer types, and top-performing cities.

## Dashboard Features

- Total Sales
- Sales Average
- Total Transactions
- Total Quantity
- Ship Mode Sales %
- Region-wise Transactions
- Monthly Quantity Ordered
- Top 5 Cities by Sales
- Category-wise Transactions
- Consumer Type Quantity Ordered

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
- Excel Dashboard
